Panduan Struktur Tabel

Pelajari setiap komponen tabel secara detail. Lihat kode di kiri dengan warna kontras tinggi, dan bandingkan dengan hasil visual di kanan.

1. Struktur Dasar

Setiap tabel HTML harus dimulai dengan tag <table>. Di dalamnya, kita wajib mendefinisikan baris menggunakan <tr> (Table Row). Setiap baris kemudian diisi oleh sel data menggunakan <td> (Table Data). Tanpa struktur ini, data tidak akan tersusun rapi.

<!-- Kerangka Tabel Paling Sederhana -->

<table>
  <tr>
    <td>Data 1A</td>
    <td>Data 1B</td>
  </tr>

  <tr>
    <td>Data 2A</td>
    <td>Data 2B</td>
  </tr>
</table>
Hasil Tampilan
Data 1AData 1B
Data 2AData 2B

2. Header & Styling CSS

Untuk memberi judul pada kolom, gunakan tag <th> (Table Header). Secara default, teks di dalam <th> akan menjadi tebal dan rata tengah. Agar tabel terlihat profesional, kita wajib menggunakan properti CSS border-collapse: collapse untuk menghapus jarak ganda di antara garis sel.

<style>
 table { width: 100%; border-collapse: collapse; }
 th, td { border: 1px solid #333; padding: 8px; }
 th { background-color: #e0e7ff; }
</style>

<table>
  <tr>
    <th>Nama</th>
    <th>Umur</th>
  </tr>
  <tr>
    <td>Andi</td>
    <td>20</td>
  </tr>
</table>
Hasil Tampilan
NamaUmur
Andi20

3. Colspan (Gabung Kolom)

Atribut colspan="n" digunakan ketika satu sel perlu memanjang ke samping meliputi beberapa kolom. Ini sangat umum digunakan untuk judul utama tabel yang mencakup seluruh sub-kolom di bawahnya.

<table>
  <tr>
    <th colspan="2">
      Data Siswa
    </th>
  </tr>

  <tr>
    <td>Budi</td>
    <td>XII</td>
  </tr>
</table>
Hasil Tampilan
Data Siswa
BudiXII

4. Rowspan (Gabung Baris)

Atribut rowspan="n" digunakan ketika satu sel perlu memanjang ke bawah meliputi beberapa baris. Biasanya digunakan untuk label kategori di sisi kiri.

<table>
  <tr>
    <td rowspan="2">
      Kelas A
    </td>
    <td>Siswa 1</td>
  </tr>

  <tr>
    <td>Siswa 2</td>
  </tr>
</table>
Hasil Tampilan
Kelas A Siswa 1
Siswa 2

5. Menyisipkan Elemen

Sel tabel <td> bersifat fleksibel. Di dalamnya, kita dapat menaruh elemen HTML lain seperti gambar (<img>), tautan (<a>), atau daftar (<ul>).

<table>
  <tr>
    <td>
      <!-- Gambar Eksternal -->
      <img src="icon.png" width="60">
    </td>
    <td>
      <b>Kamera</b>
      <br>
      Rp 5 Juta
    </td>
  </tr>
</table>
Hasil Tampilan

Panduan Langkah Demi Langkah

  4. Buat 2 Baris Data di bawah header menggunakan <tr> dan <td>.
