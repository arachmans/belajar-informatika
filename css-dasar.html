Kuasai Gaya Website

Pelajari bagaimana cara mengubah tampilan HTML yang polos menjadi karya seni digital yang memukau.

Mengapa CSS Penting?

Estetika

Mengubah warna, font, dan layout agar website terlihat profesional dan nyaman dilihat.

Responsivitas

Membuat tampilan menyesuaikan ukuran layar, baik di HP, Tablet, maupun Desktop.

Interaksi

Menambahkan animasi halus dan efek hover untuk pengalaman pengguna yang lebih baik.

Anatomi CSS

style.css
1 h1 {
2 color: #ffffff;
3 font-size: 24px;
4 }
SELECTOR Elemen yang dipilih (h1)
PROPERTY Atribut yang diubah (color)
VALUE Nilai atribut (#ffffff)

Metode Penerapan

1
Inline CSS Cepat / Kecil

Langsung menulis di atribut elemen HTML.

<h1 style="color: red;">Judul</h1>
2
Internal CSS Satu Halaman

Ditaruh di dalam tag <style> pada <head>.

<style>
  body { background: white; }
</style>
3
External CSS Best Practice

File terpisah (.css) dihubungkan dengan tag link.

<link rel="stylesheet" href="style.css">

Tugas 1: Profile Card

Layout & Box Model

  • Width kotak 300px.
  • Background putih dengan sudut melengkung (border-radius: 15px).
  • Teks di tengah (text-align: center).
<!DOCTYPE html>
<html>
<head>
  <style>
    .card {
      width: 300px;
      background-color: white;
      border-radius: 15px;
      box-shadow: 0 4px 8px rgba(0,0,0,0.1);
      padding: 20px;
      text-align: center;
      margin: 20px auto;
    }
  </style>
</head>
<body>
  <div class="card">
    <h2>Nama Saya</h2>
    <p>Siswa Web Developer</p>
  </div>
</body>
</html>
