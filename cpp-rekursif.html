Apa itu Fungsi Rekursif?

Fungsi rekursif adalah fungsi yang memanggil dirinya sendiri untuk menyelesaikan masalah. Setiap fungsi rekursif harus memiliki:

✓ Base Case (Kasus Dasar)

Kondisi untuk menghentikan rekursi

✓ Recursive Case (Kasus Rekursif)

Pemanggilan fungsi ke dirinya sendiri dengan parameter berbeda

Penting!

Tanpa base case, rekursi akan berjalan tanpa henti (infinite recursion) dan menyebabkan stack overflow!

Contoh 1: Faktorial

Basic

Faktorial dari n (n!) adalah perkalian semua bilangan positif dari 1 hingga n.
Contoh: 5! = 5 × 4 × 3 × 2 × 1 = 120

💡 Konsep:

n! = n × (n-1)! dengan base case: 0! = 1

// Fungsi Faktorial Rekursif
int faktorial(int n) {
// Base case
if (n == 0 || n == 1) {
return 1;
}
// Recursive case
return n * faktorial(n - 1);
}

// Contoh penggunaan
int main() {
int angka = 5;
cout << "Faktorial dari " << angka << " adalah: "
<< faktorial(angka) << endl;
// Output: Faktorial dari 5 adalah: 120
return 0;
}

🔄 Alur Eksekusi faktorial(5):

→ faktorial(5) = 5 × faktorial(4)
→ faktorial(4) = 4 × faktorial(3)
→ faktorial(3) = 3 × faktorial(2)
→ faktorial(2) = 2 × faktorial(1)
✓ faktorial(1) = 1 (BASE CASE)
← faktorial(2) = 2 × 1 = 2
← faktorial(3) = 3 × 2 = 6
← faktorial(4) = 4 × 6 = 24
← faktorial(5) = 5 × 24 = 120

Contoh 2: FPB (Faktor Persekutuan Terbesar)

Intermediate

FPB menggunakan algoritma Euclid: FPB(a,b) = FPB(b, a mod b)

💡 Konsep:

Algoritma Euclid: FPB dari dua bilangan dapat ditemukan dengan membagi bilangan lebih besar dengan yang lebih kecil, lalu ulangi dengan sisa pembagian

// Fungsi FPB Rekursif (Algoritma Euclid)
int fpb(int a, int b) {
// Base case
if (b == 0) {
return a;
}
// Recursive case
return fpb(b, a % b);
}

// Contoh penggunaan
int main() {
int a = 48, b = 18;
cout << "FPB dari " << a << " dan " << b
<< " adalah: " << fpb(a, b) << endl;
// Output: FPB dari 48 dan 18 adalah: 6
return 0;
}

🔄 Alur Eksekusi fpb(48, 18):

fpb(48, 18) → fpb(18, 48 % 18) → fpb(18, 12)
fpb(18, 12) → fpb(12, 18 % 12) → fpb(12, 6)
fpb(12, 6) → fpb(6, 12 % 6) → fpb(6, 0)
fpb(6, 0) → return 6 ✓

Contoh 3: KPK (Kelipatan Persekutuan Terkecil)

Intermediate

KPK menggunakan rumus: KPK(a,b) = (a × b) / FPB(a,b)

💡 Konsep:

KPK memanfaatkan fungsi FPB yang sudah kita buat sebelumnya

// Fungsi FPB (dari contoh sebelumnya)
int fpb(int a, int b) {
if (b == 0) return a;
return fpb(b, a % b);
}

// Fungsi KPK menggunakan FPB
int kpk(int a, int b) {
return (a * b) / fpb(a, b);
}

// Contoh penggunaan
int main() {
int a = 12, b = 18;
cout << "KPK dari " << a << " dan " << b
<< " adalah: " << kpk(a, b) << endl;
// Output: KPK dari 12 dan 18 adalah: 36
return 0;
}

📝 Penjelasan:

Untuk mencari KPK(12, 18):
1. Cari FPB(12, 18) = 6
2. KPK = (12 × 18) / 6 = 216 / 6 = 36

Menghitung Jumlah Digit Bilangan

⭐⭐⭐ Hard

Deskripsi Masalah:

Buatlah fungsi rekursif untuk menghitung jumlah semua digit dari sebuah bilangan.
Contoh: jumlahDigit(12345) = 1 + 2 + 3 + 4 + 5 = 15

Petunjuk:

  • • Base case: Jika n = 0, return 0
  • • Recursive case: jumlahDigit(n) = (n % 10) + jumlahDigit(n / 10)
  • • Operasi n % 10 mengambil digit terakhir
  • • Operasi n / 10 menghilangkan digit terakhir
  • • Contoh: 12345 % 10 = 5, dan 12345 / 10 = 1234

Contoh Input/Output:

Input: n = 12345 Output: 15
Input: n = 999 Output: 27
Input: n = 2024 Output: 8

🔍 Visualisasi Proses untuk n = 12345:

→ jumlahDigit(12345) = 5 + jumlahDigit(1234)
→ jumlahDigit(1234) = 4 + jumlahDigit(123)
→ jumlahDigit(123) = 3 + jumlahDigit(12)
→ jumlahDigit(12) = 2 + jumlahDigit(1)
→ jumlahDigit(1) = 1 + jumlahDigit(0)
✓ jumlahDigit(0) = 0 (BASE CASE)
Hasil: 5 + 4 + 3 + 2 + 1 + 0 = 15

// Base case: jika n = 0


// Recursive case: ambil digit terakhir + proses sisanya
