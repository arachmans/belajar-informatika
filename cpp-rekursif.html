Mengapa Kita Harus Menggunakan Rekursif?

Rekursif adalah teknik pemrograman yang powerful dengan keuntungan luar biasa:

Kode Lebih Sederhana

Membuat kode lebih pendek dan mudah dibaca

Memecah Masalah Kompleks

Mengubah masalah besar menjadi sub-masalah kecil

Solusi Alami

Cocok untuk struktur pohon dan graf

Pro Tip: Algoritma QuickSort atau MergeSort jauh lebih sederhana dengan rekursif!

Apa Itu Fungsi Rekursif?

Fungsi rekursif adalah fungsi yang memanggil dirinya sendiri. Setiap fungsi rekursif memiliki:

Kasus Dasar (Base Case)

Kondisi berhenti yang mencegah pemanggilan tak terbatas

Langkah Rekursif

Bagian yang memanggil dirinya dengan masalah lebih kecil

Visualisasi Algoritma Faktorial

factorial(5) = 5 × 4 × 3 × 2 × 1 = 120

factorial(5)
5 × factorial(4)
factorial(4)
4 × factorial(3)
factorial(3)

factorial(1)
Base Case: return 1
Langkah Perhitungan:
1 factorial(1) = 1 ← Base Case
2 factorial(2) = 2 × factorial(1) = 2 × 1 = 2
3 factorial(3) = 3 × factorial(2) = 3 × 2 = 6
4 factorial(4) = 4 × factorial(3) = 4 × 6 = 24
5 factorial(5) = 5 × factorial(4) = 5 × 24 = 120 ← Final Result

Alur Eksekusi

Warning: Tanpa base case yang benar, fungsi akan menyebabkan stack overflow!

Contoh Penggunaan Rekursif

1. Faktorial

Faktorial dari n (n!) adalah hasil perkalian semua bilangan bulat positif dari 1 hingga n.

factorial.cpp 
#include <iostream>
using namespace std;

int factorial(int n) {
    // Base case
    if (n <= 1) {
        return 1;
    }
    // Recursive step
    return n * factorial(n - 1);
}

int main() {
    int num = 5;
    cout << "Faktorial dari " << num << " adalah " << factorial(num) << endl;
    return 0;
}
$
g++ factorial.cpp -o factorial && ./factorial
Faktorial dari 5 adalah 120

2. Kelipatan Persekutuan Terkecil (KPK)

KPK dari dua bilangan adalah bilangan positif terkecil yang merupakan kelipatan keduanya.

kpk.cpp 
#include <iostream>
using namespace std;

// Fungsi FPB dengan rekursif
int fpb(int a, int b) {
    if (b == 0) return a;
    return fpb(b, a % b);
}

// Fungsi KPK
int kpk(int a, int b) {
    return (a * b) / fpb(a, b);
}

int main() {
    int num1 = 12, num2 = 18;
    cout << "KPK dari " << num1 << " dan " << num2 << " adalah " << kpk(num1, num2) << endl;
    return 0;
}
$
g++ kpk.cpp -o kpk && ./kpk
KPK dari 12 dan 18 adalah 36

3. Faktor Persekutuan Terbesar (FPB)

FPB dari dua bilangan adalah bilangan bulat positif terbesar yang membagi keduanya.

fpb.cpp 
#include <iostream>
using namespace std;

int fpb(int a, int b) {
    // Base case
    if (b == 0) {
        return a;
    }
    // Recursive step
    return fpb(b, a % b);
}

int main() {
    int num1 = 48, num2 = 18;
    cout << "FPB dari " << num1 << " dan " << num2 << " adalah " << fpb(num1, num2) << endl;
    return 0;
}
$
g++ fpb.cpp -o fpb && ./fpb
FPB dari 48 dan 18 adalah 6

Menghitung Jumlah Deret 1...n

Buat fungsi rekursif untuk menghitung jumlah deret

Contoh:

Input: n = 5
Output: 15

1 + 2 + 3 + 4 + 5 = 15

Base case: n = 1 → return 1
Recursive step: return n + fungsi(n-1)

2

Menghitung Pangkat a^b

Buat fungsi rekursif untuk menghitung pangkat

Contoh:

Input: a = 3, b = 4
Output: 81

3^4 = 3 × 3 × 3 × 3 = 81

Base case: b = 0 → return 1
Recursive step: return a × fungsi(a, b-1)

3

Mencari Jumlah Digit Bilangan

Buat fungsi rekursif untuk menghitung jumlah digit

Contoh:

Input: n = 1234
Output: 4

Digit: 1, 2, 3, 4 → Total: 4 digit

Base case: n < 10 → return 1
Recursive step: return 1 + fungsi(n/10)
