Atribut start

Menentukan angka awal penomoran.

ol-start.html

Hasil:

start="5"

  1. Item kelima
  2. Item keenam
  3. Item ketujuh

type="A" start="3"

  1. Item C
  2. Item D
  3. Item E

start selalu angka. Browser mengonversi ke format type.

Gabungan type + start

ol-combo.html

Hasil:

type="i" start="4"

  1. Masukkan data
  2. Validasi form
  3. Kirim ke server
