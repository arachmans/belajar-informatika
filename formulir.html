FormMaster

Modul Lengkap HTML Form

1. Pengantar

Sebagian besar website tidak hanya menampilkan informasi satu arah, tetapi juga menerima informasi dari penggunanya. Mulai dari login, mendaftar akun, hingga mengirim komentar—semuanya membutuhkan Form.

Dalam HTML, form berfungsi sebagai "wadah" untuk mengumpulkan input atau data dari pengguna (client) yang nantinya akan dikirim ke server untuk diproses.

2. Struktur Dasar Form

Tag <form>

Tag <form> membungkus semua elemen input. Ia memiliki dua atribut penting:

  • action: URL tujuan pengiriman data.
  • method: Cara pengiriman (GET/POST).
HTML 
<form action="proses.php" method="POST">
  ... elemen input di sini ...
</form>
Visualisasi Atribut
Wadah Form
action="/proses.php" method="POST"

3. Elemen Input Utama

A. Teks & Rahasia

Gunakan type="text" untuk nama/kota dan type="password" untuk data sensitif.

<!-- Input Biasa -->
<input type="text" name="username">

<!-- Input Rahasia -->
<input type="password" name="sandi">

B. Pilihan (Radio & Checkbox)

Radio: Pilih satu opsi (harus punya name yang sama).
Checkbox: Pilih lebih dari satu opsi. 

<!-- Radio (Satu Pilihan) -->
<input type="radio" name="jk" value="pria"> Pria

<!-- Checkbox (Banyak Pilihan) -->
<input type="checkbox" name="hobi"> Mancing
Pria Wanita
Mancing Coding

C. Data Spesifik

Tipe khusus untuk Email, Angka, dan Tanggal.

<input type="email">
<input type="number">
<input type="date">

4. Elemen Pendukung

Label, Select & Textarea

<label> Membuat form aksesibel. <select> dropdown. <textarea> teks panjang. 

<label for="kota">Kota Asal:</label>
<select id="kota">
  <option>Jakarta</option>
  <option>Bandung</option>
</select>

<textarea rows="4"></textarea>
